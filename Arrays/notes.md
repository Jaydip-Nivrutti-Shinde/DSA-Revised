----- Arrays Notes -----

> Information 
    - varibles used to store data before Array 
    - Storing multiple needs multiple variables
    - Array stores multiple data of same type
    - Stores in contineous memmory location 
    - Array can be of any type int, float, char
    - Linear data structure with indexes 0 base
    - Update & access elements using square bracs
    - int[] arr = new int[size]; - Bydefault all 0
    - length is property here not function 
    - Deep copy madee using inbuilt fun & for loop 
    - For each loop - dont use to update elements 
    - For each only used to trverse array 

----- Array List & Vectors -----

> Information 
    - dynamic array that grows according to need 
    - we uses it using collection framework 
    - square bracket not works to access elements 
    - list.add(ele), arr.set(idx,val) - updates value, list.get(idx)
    - list.size(), list.add(idx, val) - adds new at idx, list.remove(idx)
    - size updates automatically when we adds or removes elements 
    - list.clone(), Collections.reverse(list)
