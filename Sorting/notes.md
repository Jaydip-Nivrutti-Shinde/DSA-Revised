----- Sorting -----
> Information 
    - it the way of arranging the elements of the array in particular order
    - bubble sort, selection sort, insertion sort, quick sort 

    > Bubble Sort - check adjacent and swap and push largest to end each time 
        worst case - O(n^2) => Average case - O(n^2) => Best case - O(n)
    > Selection Sort - select smallest and then swap with starting ele
        worst case - O(n^2) => Average case - O(n^2) => Best case - O(n^2)  
    > Insertion Sort - Taking element from usorted array and place at its  
        correct position in sorted part by using swapping
        worst case - O(n^2) => Average case - O(n^2) => Best case - O(n) 

    - bubble sort& insertion is stable and selection sort is unstable 
    - stable means the order of duplicate elements also maintained
